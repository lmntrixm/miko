## مسیرها

`←` مسیر اصلی · `⇠` مسیر جایگزین یا خطا

- اسپلش ← معرفی ۱ تا ۳
- معرفی ۱ تا ۳ ← ورود
- ورود ⇠ ثبت‌نام
- ثبت‌نام ← کد تأیید ایمیل
- ورود ⇠ فراموشی رمز
- کد تأیید ایمیل ← شخصی‌سازی
- شخصی‌سازی ← خانه
- ورود ← خانه
- خانه ← کشف و ژانرها
- خانه ← جستجو
- خانه ← اعلان‌ها
- خانه ← فهرست کامل
- خانه ← جزئیات اثر
- خانه ← کتابخانه
- خانه ← درخواست اثر
- خانه ← پروفایل
- اعلان‌ها ← تنظیمات اعلان
- جزئیات اثر ← خواننده
- جزئیات اثر ← صفحه نویسنده
- جزئیات اثر ⇠ دیوار اشتراک
- خواننده ← نظرات چپتر
- خواننده ← تنظیمات خواندن
- خواننده ⇠ گزارش مشکل
- نظرات چپتر ← پاسخ‌های نظر
- کتابخانه ← دانلودها
- دانلودها ⇠ قطع اینترنت
- دیوار اشتراک ← خرید اشتراک
- خرید اشتراک ← درگاه بانکی
- درگاه بانکی ← بررسی پرداخت
- بررسی پرداخت ← نتیجه پرداخت
- پروفایل ← ویرایش پروفایل
- پروفایل ← مدیریت اشتراک
- پروفایل ← پشتیبانی
- پروفایل ← دعوت و هدیه
- مدیریت اشتراک ← تاریخچه پرداخت
- پشتیبانی ← قوانین و حریم خصوصی

## حالت‌های سراسری (از هر صفحه)

- بارگذاری ← `Loading` (اسکلتون، بعد از ۳۰۰ms تأخیر)
- قطع اینترنت ← `Offline` (بنر زرد + فقط چپترهای دانلودشده)
- لیست خالی ← `EmptyLibrary` / جستجوی بی‌نتیجه ← `NoResults`
- خطای 402 / اشتراک منقضی ← `Paywall`
- خطای 426 / نسخه قدیمی ← `AppUpdate` (اختیاری یا اجباری)
- خطای 503 ← `Maintenance`
- خطای 401 ← `AuthLogin`
- کاربر قبلاً ثبت‌نام‌کرده: `AuthLogin` ← خانه (بدون OTP)
- تبلت ← `TabletReader`؛ گوشی افقی ← `ReaderLandscape`; وبتون ← `ReaderWebtoon`
