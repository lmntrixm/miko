# نقشه API (پیشنهادی)

REST، نسخه v1، احراز هویت با JWT، صفحه‌بندی cursor-based. نام‌ها پیشنهادی‌اند و تیم بک‌اند نهایی می‌کند.

## ورود و حساب

| صفحه | متد | مسیر | توضیح | کش |
|---|---|---|---|---|
| ثبت‌نام | POST | `/v1/auth/signup` | نام، ایمیل، رمز ← ارسال کد | — |
| کد تأیید | POST | `/v1/auth/verify` | کد ۶ رقمی ← توکن | — |
| ورود | POST | `/v1/auth/login` | ایمیل + رمز | — |
| فراموشی رمز | POST | `/v1/auth/password/reset` | ارسال کد و ثبت رمز جدید | — |
| شخصی‌سازی | PUT | `/v1/me/preferences` | ژانرها و زبان ترجیحی | — |
| ویرایش پروفایل | PATCH | `/v1/me` | نام، تصویر، رمز | — |
| حذف حساب | DELETE | `/v1/me` | حذف دائمی پس از تأیید | — |

## رویدادهای لحظه‌ای (Push / WebSocket)

`chapter.published` · `comment.reply` · `subscription.expiring` · `payment.confirmed` · `download.completed` (محلی)

## کدهای خطای مشترک

- 401 نشست منقضی ← ورود
- 402 نیاز به اشتراک ← Paywall
- 409 بیش از ۲ دستگاه
- 426 نسخه قدیمی ← به‌روزرسانی
- 503 تعمیر و نگهداری

## تصاویر صفحات

آدرس امضاشده با انقضای ۱۰ دقیقه، WEBP در دو کیفیت، واترمارک نامرئی شناسه کاربر؛ صفحه بعدی از قبل بارگذاری شود.
