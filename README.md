# میکو — بسته شروع برای Claude Code

## چطور شروع کنید

1. این پوشه را از حالت فشرده خارج کنید. این همان پوشه پروژه است و کد هم کنار همین فایل‌ها ساخته می‌شود.
2. ترمینال را در این پوشه باز کنید و `claude` را اجرا کنید (یا پوشه را در Claude Code دسکتاپ باز کنید).
3. Claude Code فایل `CLAUDE.md` را خودش می‌خواند و قواعد پروژه (RTL، فونت، توکن‌ها، جای‌خالی‌ها) را رعایت می‌کند.

## اولین پیام پیشنهادی

> CLAUDE.md و docs/screens.md را بخوان. اپ موبایل را با [Flutter یا React Native] شروع کن: ساختار پروژه، تم تیره و روشن از design/tokens، فونت Vazirmatn، RTL و کامپوننت‌های پایه. بعد صفحه‌های ورود و ثبت‌نام را از روی design/screens بساز و هر صفحه را با تصویر طراحی مقایسه کن.

پیام‌های بعدی، به ترتیب:
- «خانه (HomeTypes)، جزئیات اثر و خواننده را بساز.»
- «کتابخانه، دانلودها و حالت آفلاین را اضافه کن.»
- «جریان اشتراک و پرداخت را با داده ساختگی بساز.»
- «پنل ادمین را با Next.js در پوشه admin/ شروع کن، از داشبورد و منوی کناری.»

## محتوای بسته

- `CLAUDE.md` — راهنمای پروژه برای Claude Code
- `docs/screens.md` — فهرست ۱۴۱ صفحه، اندازه، مسیر پیشنهادی و لینک‌ها
- `docs/flows.md` — جریان‌های کاربر و حالت‌های سراسری
- `docs/api.md` — نقشه API پیشنهادی
- `design/screens/` — تصویر همه صفحه‌ها
- `design/html/` — HTML ایستای همه صفحه‌ها (`design/index.html` فهرستشان است)
- `design/design-system.md` — اصول، رنگ، تایپوگرافی، حرکت و کامپوننت‌ها
- `design/tokens/` — توکن‌ها برای Dart، TypeScript، JSON، Tokens Studio و DTCG

## هنوز لازم است

قیمت طرح‌ها، ایمیل پشتیبانی، دامنه، لینک فروشگاه‌ها، لوگوی نهایی و کاورهای دارای مجوز. تا این‌ها نیامده، در کد با همان برچسب‌های `[قیمت]` و مشابه می‌مانند.
