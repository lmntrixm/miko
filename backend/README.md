# بک‌اند میکو

Fastify + TypeScript + PostgreSQL. مسیرها از `docs/api.md` (پیشوند `/v1`). خطاها همیشه `{ error: { code, message } }` با پیام فارسی‌اند.

## اجرا
```
cd backend && npm install
SEED=1 npm run dev        # بدون DATABASE_URL از Postgres داخل‌پردازه (PGlite، پوشه .pglite) استفاده می‌کند
DATABASE_URL=postgres://… npm run migrate && npm start
npm test
```
متغیرها: `PORT`، `DATABASE_URL`، `JWT_SECRET` (در production حداقل ۳۲ نویسه)، `FREE_MODE` (پیش‌فرض روشن؛ `FREE_MODE=0` یعنی پولی). در حالت رایگان همهٔ چپترها و دانلود بدون اشتراک باز است؛ سقف ۲ دستگاه می‌ماند. `GET /v1/config` وضعیت را به کلاینت می‌گوید.

## چه چیزی ساخته شده
- ورود/ثبت‌نام: `signup` ← `verify` (کد ۶ رقمی، ۱۰ دقیقه، ۵ تلاش) ← توکن؛ `login` (قفل ۱۵ دقیقه بعد از ۵ رمز اشتباه)، `password/reset`، `/me`، ترجیحات، ویرایش و حذف حساب.
- کاتالوگ: فهرست/جستجو با cursor، رتبه‌ها، ژانرها، جزئیات، چپترها (قفل بعد از ۳ چپتر رایگان)، طرح‌ها.
- خواندن: صفحات با آدرس امضاشدهٔ ۱۰ دقیقه‌ای (۴۰۲ بدون اشتراک)، پیشرفت خواندن، دانلود با سقف ۲ دستگاه (۴۰۹) و مدیریت دستگاه‌ها.

## هنوز نیست
- ارسال واقعی کد (`Mailer`): در production عمداً بدون پیاده‌سازی بالا نمی‌آید.
- سرو فایل صفحات (آدرس‌ها امضا می‌شوند ولی ذخیره‌ساز تصویر وصل نیست)؛ آپلود چپتر.
- پرداخت و درگاه، کدهای تخفیف/هدیه، قیمت طرح‌ها (`null` = `[قیمت]`).
- نظرات، درخواست اثر، خانه، نویسنده‌ها، کتابخانه، مسیرهای `/v1/admin/*` و اعلان.
- وصل کردن اپ موبایل و پنل ادمین به این API (هنوز mock هستند).
