نقشه API — هر صفحه چه داده‌ای لازم دارد

پیشنهاد REST · نسخه v1 · احراز هویت با توکن JWT · همه پاسخ‌ها صفحه‌بندی cursor-based · نام‌ها پیشنهادی‌اند و تیم بک‌اند نهایی می‌کند

صفحهمتدمسیرتوضیحکش
خانه GET /v1/home?type=manga بنر، ادامه خواندن، رتبه‌ها، بروزترین‌ها ۵ دقیقه
کشف GET /v1/genres ژانرها و تعداد آثار ۱ ساعت
جستجو GET /v1/titles?q=&type=&lang=&status= نتایج + پیشنهاد املایی —
فهرست کامل GET /v1/titles/ranked?by=popular&range=week رتبه‌بندی ۱۰ دقیقه
جزئیات اثر GET /v1/titles/{id} اطلاعات، نویسنده، ژانرها ۱۰ دقیقه
لیست چپترها GET /v1/titles/{id}/chapters?range=200-250 چپترها + قفل/خوانده‌شده ۱ دقیقه
خواننده GET /v1/chapters/{id}/pages?lang=fa آدرس صفحات (امضاشده) —
پیشرفت خواندن PUT /v1/me/progress/{chapterId} صفحه فعلی؛ همگام بین دستگاه‌ها —
نشان کردن POST /v1/me/bookmarks افزودن/حذف —
کتابخانه GET /v1/me/library?tab=reading در حال خواندن، نشان‌شده، تاریخچه —
دانلود POST /v1/chapters/{id}/download مجوز دانلود دستگاه —
نویسنده GET /v1/authors/{id} معرفی و آثار ۱ ساعت
رویدادهای لحظه‌ای (Push/WebSocket)chapter.published · comment.reply · subscription.expiring · payment.confirmed · download.completed (محلی)
